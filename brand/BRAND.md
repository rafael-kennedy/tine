# Tine brand

## Mark

A tuning fork in brass, with two pairs of teal arcs for its vibration. The fork is the reference pitch: the instrument that sounds the same every time, which is the language's promise of replayable, seeded music. Its tines also echo the tines of an electric piano, which is Tine's default instrument.

| File | Use |
| --- | --- |
| `tine-mark.svg` | the mark alone, transparent |
| `tine-icon.svg`, `icon-*.png` | app and file icon on the ink square (16 to 1024 px) |
| `tine-logo.svg` | mark plus wordmark (set in Fraunces; text inherits `currentColor`) |
| `logo-dark.png`, `logo-light.png` | rendered logo on each background |
| `social-card.png` | 1200 x 630 link preview |

Keep the arcs teal and the fork brass. Do not rotate the mark or put it on busy images. Minimum size for the mark with arcs: 16 px.

## Color

| Token | Dark | Light | Role |
| --- | --- | --- | --- |
| ink | `#14161c` | `#f6f1e7` | background |
| text | `#e9e4d8` | `#22252c` | body text |
| brass | `#d4a944` | `#a87d12` | primary accent, the fork, notes |
| teal | `#3aa6a0` | `#22807b` | secondary accent, vibration, active state |
| coral | `#e0604f` | `#c2412f` | errors, keywords |

The dark theme is the default: live coding happens on stages and in dim rooms.

## Type

- **Fraunces** (600) for the wordmark and headings: a warm, slightly old-style serif, like engraving on an instrument.
- **Inter** for interface text.
- **JetBrains Mono** for code.

All three are open fonts from Google Fonts. Every surface falls back to system fonts offline.

## Voice

Plain and musical. Talk about bars, notes and takes rather than cycles, events and runs. Errors explain what to do next.
