# Tine in JetBrains IDEs

**The full plugin is in `plugin/`** (see `plugin/README.md`): highlighting, completion and errors from `tine lsp`, run configurations, and these templates scoped to Tine files. Use it on IntelliJ IDEA 2025.2+ or a paid JetBrains IDE. The import-only files below are for IDEs where the plugin cannot run.

Works in IntelliJ IDEA, WebStorm, PyCharm, GoLand, RustRover and the rest. Everything here is generated by `bun scripts/gen-jetbrains.ts` from `src/core/builtins.ts` and `src/core/docs.ts`. Regenerate after changing a builtin.

There are two routes. Pick one, or use both.

| | Live Templates (`tine-settings.zip`) | Language server (`tine lsp`) |
| --- | --- | --- |
| Needs | nothing | `tine` on your PATH, plus LSP4IJ or IntelliJ 2026.x |
| Completion | every builtin, statement, scale, drum and instrument | the same, aware of context: chord qualities after `@`, only functions after `.`, plus your own `let` names |
| Inserts | the call with argument placeholders: `fast(n)`, Tab to the next | the bare name; signature help shows the arguments as you type |
| Docs in the popup | signature and one line | full hover, signature help as you type |
| Errors | none | live diagnostics, including errors that only happen while playing |
| Scope | templates are on everywhere except common languages (see below) | only `.tine` files |

## 1. Highlighting (do this first)

Settings, Editor, TextMate Bundles, `+`, then choose the `tine-bundle` folder. This gives colors, bracket matching and `--` comments for `.tine` files.

## 2a. Completions by import

1. File, Manage IDE Settings, Import Settings.
2. Choose `tine-settings.zip`. Keep "Live templates" ticked. Restart when asked.
3. Open a `.tine` file and type `fa`. `fast` appears in the completion popup with its signature. Enter (or Tab) expands it to `fast(n)` with `n` selected. Tab moves to the next argument.

You get three groups under Settings, Editor, Live Templates. Switch any of them off there.

- **Tine statements** (13): `piece`, `voice`, `section`, `let`, `groove`, `tempo`, `key`, `seed`, `meter`, `tuning`, `form` and the like.
- **Tine functions** (165): one per builtin. A function whose first argument is a pattern expands without it, ready for method calls: type `[c e g].` then `fa`, get `[c e g].fast(n)`.
- **Tine words** (84): scales, drums and instruments, with their notes.

Instead of importing, you can copy the three files in `templates/` to the IDE's `templates` folder (on macOS, `~/Library/Application Support/JetBrains/<IDE><version>/templates/`) and restart.

Why templates show up outside `.tine` files: a file highlighted by a TextMate bundle has no template context of its own, so the templates use "Everywhere" and switch off Java, Kotlin, Python, JavaScript, TypeScript, HTML, XML, CSS, JSON, YAML, SQL, Markdown, shell, Go, Rust, PHP, Ruby and C/C++. Plain text files still see them.

## 2b. Completions from the language server

**LSP4IJ** (free plugin by Red Hat, all JetBrains IDEs):

1. Install LSP4IJ from the Marketplace.
2. Settings, Languages & Frameworks, Language Servers, `+`.
3. Template, Import from custom template, choose the `lsp4ij/tine` folder. OK.

**IntelliJ IDEA 2026.x** (built in, no plugin): Settings, Languages & Frameworks, Language Servers, Add LSP Server. Executable `tine`, arguments `lsp` (replace the default `--stdio`), file name pattern `*.tine`. This setting is per project.

If the IDE cannot find `tine`, use its full path (`which tine`). Apps started from the Dock on macOS do not see your shell's PATH.
